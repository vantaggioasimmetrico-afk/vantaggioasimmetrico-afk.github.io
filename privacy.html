Ambito

Questa informativa riguarda l'app Vantaggio Asimmetrico Publisher, usata dal titolare del canale YouTube Vantaggio Asimmetrico per gestire il proprio canale tramite la YouTube Data API. Descrive quali dati utente Google l'app legge, come li usa, conserva, protegge e condivide. Contatti: vantaggioasimmetrico@gmail.com.

Dati utente Google a cui accede

Solo dopo l'autorizzazione esplicita del titolare, tramite l'ambito OAuth https://www.googleapis.com/auth/youtube, l'app legge e modifica:

  • dati del canale: nome, identificativo, descrizione, parole chiave, banner;
  • dati dei video del canale: identificativo, titolo, descrizione, tag, categoria, lingua, stato di pubblicazione e data di pubblicazione programmata.

L'app non accede a email, contatti, dati di pagamento, cronologia, commenti, né ai dati di spettatori, iscritti o altri utenti.

Come li usa

Solo per le operazioni richieste dal titolare:

  • trovare i video caricati sul canale;
  • applicare titoli, descrizioni, tag, categoria, lingua e stato di pubblicazione;
  • aggiornare descrizione, parole chiave e banner del canale.

I dati non sono usati per pubblicità, profilazione, analisi statistiche o altri scopi.

Come li conserva e per quanto

  • L'app non ha server né database. I dati letti vengono usati durante l'esecuzione e non sono archiviati altrove.
  • Il token di accesso OAuth è salvato in un file sul computer del titolare. Resta lì finché il titolare non revoca l'accesso o cancella il file.

Come li protegge

  • Le comunicazioni con le API di Google avvengono solo in HTTPS.
  • Il token e le credenziali dell'app restano sul computer del titolare, protetti dal suo account di sistema, e sono esclusi da qualsiasi repository di codice.
  • L'app richiede un solo ambito OAuth, quello necessario.

Condivisione

  • Google / YouTube. L'app usa i Servizi API di YouTube. I dati sono trattati da Google secondo le Norme sulla privacy di Google.
  • Anthropic. Il titolare può eseguire l'app tramite Claude Code, l'assistente AI di Anthropic, che lancia lo script sul suo computer. In quel caso i dati letti dall'API transitano anche da Anthropic, solo per eseguire le operazioni richieste, secondo la sua informativa sulla privacy.

I dati non sono venduti, ceduti o comunicati ad altri soggetti.

Uso limitato

L'uso e il trasferimento ad altre app delle informazioni ricevute dalle API di Google rispettano le Norme sui dati utente dei servizi API di Google, inclusi i requisiti di Uso limitato. In particolare, i dati utente Google:

  • non sono usati per pubblicità di alcun tipo;
  • non sono venduti a data broker o rivenditori di informazioni;
  • non sono usati per valutazioni di credito o prestiti;
  • non sono usati per creare database;
  • non sono usati per sviluppare, migliorare o addestrare modelli di intelligenza artificiale o machine learning generalizzati.

Revoca e cancellazione

L'accesso si revoca in qualsiasi momento dalla pagina Accesso di terze parti dell'account Google. Dopo la revoca l'app non può più leggere né modificare il canale. Cancellando il file del token dal computer del titolare non resta alcun dato conservato dall'app. Per qualsiasi richiesta: vantaggioasimmetrico@gmail.com.

Questo sito

Il sito è ospitato da GitHub Pages. GitHub può registrare dati tecnici come l'indirizzo IP per motivi di sicurezza. Il sito non usa cookie, analitiche o risorse esterne.

Modifiche

Se cambia il modo in cui l'app usa i dati utente Google, questa pagina viene aggiornata con la nuova data prima che il cambiamento sia applicato.

English

Privacy Policy

This policy covers Vantaggio Asimmetrico Publisher, the app the owner of the YouTube channel Vantaggio Asimmetrico uses to manage the channel through the YouTube Data API. Contact: vantaggioasimmetrico@gmail.com.

Google user data accessed

Only after the owner's explicit consent, through the OAuth scope https://www.googleapis.com/auth/youtube, the app reads and updates: channel data (name, ID, description, keywords, banner) and the channel's video data (ID, title, description, tags, category, language, privacy status, scheduled publish time). It does not access email, contacts, payment data, history, comments, or data of viewers, subscribers or other users.

How the data is used

Only to perform the owner's requests: find uploaded videos, apply titles, descriptions, tags, category, language and privacy status, and update the channel description, keywords and banner. No advertising, profiling or analytics.

Storage and retention

The app has no servers or databases. Data read from the API is used during execution and not archived elsewhere. The OAuth token is stored in a file on the owner's computer until the owner revokes access or deletes the file.

Protection

All API traffic uses HTTPS. The token and app credentials stay on the owner's computer, protected by the owner's system account, and are excluded from any code repository. The app requests a single, necessary OAuth scope.

Sharing

Google processes data under the Google Privacy Policy. The owner may run the app through Claude Code, Anthropic's AI assistant; in that case data read from the API also passes through Anthropic, only to perform the requested operations, under the Anthropic Privacy Policy. Data is not sold, transferred or disclosed to anyone else.

Limited Use

Vantaggio Asimmetrico Publisher's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not used for advertising, not sold to data brokers or information resellers, not used for credit or lending decisions, not used to create databases, and not used to develop, improve or train generalized AI or machine learning models.

Revocation and deletion

Access can be revoked at any time from the Google Account third-party access page. Deleting the token file from the owner's computer leaves no data stored by the app.

Changes

If the way the app uses Google user data changes, this page is updated with a new date before the change takes effect.
