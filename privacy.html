Informativa sulla privacy

Ultimo aggiornamento: 28 ottobre 2026

Titolare

Vantaggio Asimmetrico Publisher è uno strumento interno del canale YouTube Vantaggio Asimmetrico. Contatti: [EMAIL].

A cosa serve

Lo strumento è uno script che gira sul computer del titolare del canale. Usa la YouTube Data API per aggiornare i video e le impostazioni del canale del titolare. Non è offerto ad altri utenti.

Dati a cui accede

Solo dopo l'autorizzazione esplicita del titolare, tramite l'ambito OAuth https://www.googleapis.com/auth/youtube, lo strumento accede a:

  • informazioni del canale: nome, descrizione, parole chiave, banner;
  • elenco e metadati dei video del canale: titolo, descrizione, tag, categoria, lingua, stato di pubblicazione.

Non accede a email, contatti, dati di pagamento, né ai dati di spettatori, iscritti o altri utenti.

Come li usa

Solo per leggere e aggiornare i video e il canale del titolare, su sua richiesta. Nessuna profilazione, nessuna pubblicità, nessuna vendita di dati.

Dove sono conservati

Il token di accesso OAuth e i dati letti restano sul computer del titolare. Lo strumento non ha server né database.

Terze parti

  • Google / YouTube. Lo strumento usa i Servizi API di YouTube. I dati sono trattati da Google secondo le Norme sulla privacy di Google.
  • Anthropic. Il titolare può eseguire lo strumento tramite Claude Code, l'assistente AI di Anthropic. In quel caso i dati letti dall'API transitano anche da Anthropic, secondo la sua informativa sulla privacy.

Nessun'altra condivisione.

Uso limitato

L'uso e il trasferimento delle informazioni ricevute dalle API di Google rispettano le Norme sui dati utente dei servizi API di Google, inclusi i requisiti di Uso limitato.

Revoca e cancellazione

L'accesso si revoca in qualsiasi momento dalla pagina Accesso di terze parti dell'account Google. Cancellando il file del token dal computer del titolare non resta alcun dato conservato dallo strumento.

Questo sito

Il sito è ospitato da GitHub Pages. GitHub può registrare dati tecnici come l'indirizzo IP per motivi di sicurezza. Il sito non usa cookie, analitiche o risorse esterne.
